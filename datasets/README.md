# datasets · 练习数据

## 建议的数据集（都免费、可商用需注意授权）
| 用途 | 数据集 | 来源 |
|---|---|---|
| W1–W4 基础练习 | MySQL 官方 employees / sakila 示例库 | dev.mysql.com |
| W2 电商聚合 | 电商订单模拟表（自己造 1 万行） | 用 Python faker 生成 |
| W7 脏数据清洗 | 公开天气 / 房价 / 电影数据集 | Kaggle Datasets（注意授权） |
| 综合分析 | 电商用户行为（点击/加购/下单/支付） | 天池公开数据集 |

## 目录约定
- `schema.sql`：所有建表语句（DDL）
- `*.csv`：小于 5MB 的数据可直接入库；大于 5MB 放 `raw_large/`（已被 .gitignore 忽略）
- 每个数据集在本文件登记：来源链接、授权方式、行数、字段说明

## 注意
- **不要上传有版权争议的付费课程资料、盗版电子书**，会导致仓库被投诉。
- 数据来源要写清楚，这是数据从业者的基本职业素养，面试官会看。
