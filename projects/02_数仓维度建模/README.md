# 02 · 数仓维度建模：外卖平台（D56 产出）

## 任务
为「外卖平台」设计一套数仓表：1 张事实表 + 4 张维度表，画出星型模型。

## 交付物
- `ddl.sql`：全部建表语句（含字段注释、主外键、分区字段）
- `star_schema.png`：星型模型图（draw.io / Excalidraw 画完导出）
- `设计说明.md`：为什么这么设计（下面 6 个问题必须回答）

## 设计说明必须回答的 6 个问题（面试必问）
1. 业务过程是什么？粒度（一行代表什么）定在哪一层？
2. 事实表选哪种类型（事务事实表 / 周期快照 / 累积快照）？为什么？
3. 4 张维度表分别是什么？哪些字段做退化维度？
4. 度量值有哪些？可加 / 半可加 / 不可加分别是哪些？
5. 为什么数仓要冗余（反范式）？和业务库的三范式冲突在哪？
6. 如果要支持「按小时看 GMV」和「按城市看复购率」，你的模型要改什么？

## 参考骨架（自己填完再对答案）
```
事实表：fact_order（订单明细）
  维度外键：date_key, user_key, shop_key, rider_key
  度量：order_amount, discount_amount, delivery_fee, pay_amount
  退化维度：order_id, order_status
维度表：dim_date / dim_user / dim_shop / dim_rider
```
