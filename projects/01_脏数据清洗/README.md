# 01 · 脏数据清洗项目（D46 产出）

## 项目一句话
用 SQL + pandas 清洗一份真实脏数据，产出「清洗前 vs 清洗后」的质量对比报告。

## 目录
- `raw/`：原始数据（不修改，只读）
- `scripts/`：清洗脚本（`clean.sql`、`clean.py`）
- `cleaned/`：清洗后数据
- `report/`：对比报告（`清洗报告.md` + 前后质量指标表）
