# 03 · 业务分析 SQL 十题（D57 产出）

每题一个 `.sql` 文件，文件头必须写三行注释：**业务问题 / 用到的核心语法 / 结果怎么解读**。

| # | 文件 | 业务问题 | 核心语法 |
|---|---|---|---|
| 01 | `01_GMV趋势.sql` | 近 30 天 GMV 与订单量趋势 | DATE_FORMAT + GROUP BY |
| 02 | `02_Top品类.sql` | 每个品类销量前 3 的商品 | ROW_NUMBER + 分组 TopN |
| 03 | `03_新客占比.sql` | 每月新客数与新客 GMV 占比 | 首单日期 + CASE WHEN |
| 04 | `04_复购率.sql` | 30 日复购率与复购用户画像 | 用户维度聚合 + HAVING |
| 05 | `05_次日留存.sql` | 注册次日 / 7 日 / 30 日留存率 | LEFT JOIN + DATEDIFF |
| 06 | `06_转化漏斗.sql` | 曝光→点击→加购→下单→支付漏斗 | 条件聚合 / 多表连接 |
| 07 | `07_连续活跃.sql` | 连续活跃 ≥7 天的用户 | ROW_NUMBER 差值法 |
| 08 | `08_异常检测.sql` | 找出金额或频次异常的用户 | 窗口 AVG/STDDEV + 3σ |
| 09 | `09_同环比.sql` | GMV 的月环比与年同比 | LAG + 日期偏移 |
| 10 | `10_用户分群.sql` | RFM 模型给用户分层 | NTILE / CASE WHEN 分箱 |

## 文件头模板
```sql
-- 业务问题：近 30 天每天的 GMV、订单量、客单价趋势
-- 核心语法：DATE_FORMAT、GROUP BY、聚合函数、ORDER BY
-- 结果解读：客单价 = GMV / 订单量，若订单量涨而客单价跌，说明拉新质量下降或促销力度过大
```
