## 三个最大的坑（我的复盘，D60 填写）

1. **NULL**：`WHERE col <> 'A'` 查不出 `col IS NULL` 的行——三值逻辑坑了我 ____ 次。
2. **一对多连接后聚合翻倍**：必须先聚合再连接，或改用窗口函数。
3. **看题解 ≠ 会做**：看懂之后关掉重写，才算真的会。
