# mock-exams · 模拟笔试

两套 45 分钟限时模拟卷，检验 60 天成果。

## 规则（严格执行，否则测不出真实水平）
1. 限时 45 分钟，中途不查资料、不看笔记、不用 AI
2. 12 道题混合难度：Easy 4 / Medium 6 / Hard 2
3. 题目来源：牛客「SQL大厂面试真题」随机抽卷，或 LeetCode Database 混合
4. 做完立刻判分，把错题记进 `notes/99_我的错题本.md`

## 每套的目录结构
```
mock1/
├── 题目.md        ← 12 道题的题面（截图或抄录）
├── 我的答案.sql   ← 限时内写的原始答案，不许事后修改
├── 标准答案.sql   ← 判分后补上
└── 复盘.md        ← 正确率、耗时分布、错因分类、下一步补什么
```

## 复盘.md 模板
| 指标 | mock1 | mock2 |
|---|---|---|
| 日期 | | |

| 用时 | /45min | /45min |

**验收线：正确率 ≥80%（即 ≥10/12）。达不到就把对应周重学一遍。**
