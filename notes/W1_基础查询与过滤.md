## 一、语法速查（用自己的话写）

### SELECT 三件套
```sql
SELECT 列1, 列2 AS 别名     -- 取什么
FROM 表名                   -- 从哪取
WHERE 条件                  -- 过滤哪些行
ORDER BY 列 ASC|DESC        -- 怎么排
LIMIT n OFFSET m;           -- 取多少
```

### 过滤条件
| 写法 | 含义 | 注意 |
|---|---|---|
| `=` `>` `<` `>=` `<=` `<>` | 比较 | 字符串和日期要加单引号 |
| `AND` / `OR` | 逻辑 | **AND 优先级高于 OR，混用必须加括号★** |
| `IN (a,b,c)` | 属于集合 | 比一长串 OR 好读 |
| `BETWEEN a AND b` | 区间 | **闭区间，含两端★** |
| `LIKE 'A%'` / `LIKE '%A%'` | 模糊 | `%` 任意多字符，`_` 单个字符；**前导 `%` 会让索引失效** |
| `IS NULL` / `IS NOT NULL` | 判空 | **不能用 `= NULL`★** |

## 二、踩过的坑（每条写：现象 → 原因 → 正确写法）

### 坑 1：以为 3306 没监听
- **现象**：用某些工具查端口，显示 3306 没有监听，以为服务没起来
- **原因**：查询工具本身权限/环境受限；实际 `E:\MySQL\log\mysql-error.log` 里明确写着 `ready for connections ... port: 3306`
- **正确做法**：**判断 MySQL 是否可用，以错误日志和实际连接为准**，别只信端口扫描工具。`mysql -u root -p` 能连上（哪怕报密码错）就说明服务是活的

### 坑 2：mysql 不在 PATH，每次要敲全路径
- **现象**：命令行输入 `mysql` 提示不是内部或外部命令
- **原因**：安装时没勾选"加入 PATH"，且是 ZIP/自定义方式装的
- **正确写法**（一次性，不需要管理员）：
```powershell
$bin = "C:\Program Files\MySQL\MySQL Server 8.4\bin"
$old = [Environment]::GetEnvironmentVariable("Path","User")
if ($old -notlike "*$bin*") { [Environment]::SetEnvironmentVariable("Path", "$old;$bin", "User") }
# 关掉当前终端重开一个，再敲 mysql --version 验证
```

## 三、可以背的口诀 / 模板 SQL

1. **拿到一张陌生表的四步**：`SELECT * FROM t LIMIT 20` 看长相 → `DESC t` 看结构 → `SELECT COUNT(*)` 看规模 → 挑几个字段 `SELECT DISTINCT` 看取值范围
2. **AND 比 OR 先算**，混用一律加括号
3. **BETWEEN 含两端**，`IN` 不含区间
4. **判空只能用 IS NULL**，`= NULL` 永远返回 UNKNOWN
5. **分页**：`LIMIT 每页条数 OFFSET (页码-1)*每页条数`
