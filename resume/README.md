## 写简历时的四条注意
1. **数字必须真**：面试官会让你打开 GitHub 当场看，对不上就是造假。
2. **别写"学习了 SQL"**：写"完成了什么、产出了什么、正确率多少"。
3. **GitHub 链接放在头部信息栏**，并确认仓库是 **public**。
4. **仓库 README 的数据看板要填满**——面试官点开只看 README，不会逐个文件翻。

## 投递前 60 秒自检清单
- [ ] 仓库是 public，不是 private

- [ ] 没有任何版权资料、密码、个人隐私信息
